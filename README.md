# LOGOwork

Static app-icon launcher for the student health record system.

## Target app

https://83eb1c6582cf666c17.v2.appdeploy.ai/

## Logo

The app uses a self-contained local SVG icon at `public/icon.svg`, inspired by the requested Chibi Nurse Holding Phone logo so the launcher works even when external image hosts are blocked.

## Run locally

```bash
npm start
```

Open http://localhost:4173 in a browser.

## Local check

```bash
npm test
```
